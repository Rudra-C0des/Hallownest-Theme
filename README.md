# Hallownest

A dark, vibrant Jekyll theme inspired by Hallownest from Hollow Knight. Neon blue and orange on a void-blue black.

## Install (GitHub Pages)

In your site's `_config.yml`:

```yaml
remote_theme: yourusername/shallow-nest
plugins:
  - jekyll-remote-theme
```

## Configure

Set `title`, `tagline`, `author`, and a `nav` list in `_config.yml`.

## Run locally

```
bundle install
bundle exec jekyll serve --livereload
```
